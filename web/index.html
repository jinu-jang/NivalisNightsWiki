Add your local reference pack

Explore quests, compare replies, and follow every branch with a data pack from your own local game installation.

  2. Keep its data folder beside this guide’s index.html, then open the guide through your local HTTP server.

The source-only public edition does not include extracted game text. A public data pack is included only when separately approved for publication.
